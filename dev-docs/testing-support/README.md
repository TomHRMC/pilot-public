# Test plans and test results

> **Snapshot note — historical working papers.** The files in this folder are published as written during the research and build (October 2025 – October 2026; full-time build March – September 2026) to show how the work was actually run. They are not maintained. Figures, statuses ("ACTIVE", "READY", "LIVE", "in production"), version numbers, plans and test-run summaries were true on the day they were written, and many were later superseded. Some files use the project's earlier name (AevoFab) or address the author or an AI agent directly. Words such as "prod", "production", "live", "real signup", "beta" and "customer" describe the author's own tests on the one pre-release AWS environment or the local dev database: there were no outside users, customers or payments, and "Lang Electric" is the author's own test tenant. References to `pilot-launch-plan.md`, the batch registry and launch-gate documents point to private planning files that are not in this snapshot, as do some other working documents these files name.
>
> For current, checked figures see [`PROVENANCE.md`](../../PROVENANCE.md) and [`dev-docs/diligence/`](../diligence/README.md); for how the work was governed, see [`Pilot-Delivery-and-Governance.md`](../analysis/Pilot-Delivery-and-Governance.md). The product was never released, never carried customer traffic, and is hibernated.
